# پیگیری فاکتور و ارسال چندپارتی

جایگزین وب فایل اکسل «پیگیری فاکتور و ارسال چندپارتی». چند نفر هم‌زمان می‌توانند کار کنند و همه محاسبات (مانده، سرشکن هزینه حمل، بهای تمام‌شده، وضعیت‌ها) خودکار انجام می‌شود.

## مدل داده (۵ جدول)

| جدول | نقش | کلید خارجی |
|---|---|---|
| `invoices` | سربرگ فاکتور | — |
| `invoice_items` | اقلام هر فاکتور | `invoice_id` |
| `shipments` | پارت‌های ارسال | — |
| `allocations` | چه تعداد از کدام قلم در کدام پارت رفته | `item_id` + `shipment_id` |
| `payments` | پرداخت‌های هر فاکتور | `invoice_id` |
| `users` | کاربران سیستم (ورود با موبایل و رمز) | — |

هیچ ستون محاسباتی ذخیره نمی‌شود؛ همه در لحظه از روی همین ۵ جدول حساب می‌شوند (`src/lib/queries.ts`).

## اجرا روی کامپیوتر خودتان

```bash
docker run -d --name khanum-pg -e POSTGRES_PASSWORD=khanum -e POSTGRES_DB=khanum -p 55432:5432 postgres:16-alpine
cp .env.example .env.local   # سپس مقادیر را ویرایش کنید
npm install
npm run db:init
npm run dev
```

## انتشار روی اینترنت (Vercel + Neon)

۱. این پوشه را روی GitHub بگذارید.
۲. در [neon.tech](https://neon.tech) یک پروژه Postgres رایگان بسازید و connection string آن را بردارید.
۳. در [vercel.com](https://vercel.com) با «Import Project» همین مخزن را وارد کنید و در Environment Variables دو مقدار بدهید:
   - `DATABASE_URL` = رشته اتصال Neon
   - `AUTH_SECRET` = یک رشته تصادفی بلند برای امضای کوکی
۴. بعد از اولین دیپلوی، یک‌بار جداول را بسازید:
   ```bash
   DATABASE_URL="رشته-اتصال-Neon" node scripts/init-db.mjs
   ```
۵. آدرس Vercel را باز کنید، کاربر اول را بسازید، و بعد در صفحه «کاربران» همکارانتان را اضافه کنید.

## ظاهر

- طراحی بر پایه **Geist** (دیزاین‌سیستم Vercel): توکن‌های رنگ، شعاع ۶/۱۲ پیکسل و تایپوگرافی همان سیستم.
- فونت فارسی **Vazirmatn** با `next/font` روی سرور خودمان میزبانی می‌شود (بدون CDN)؛ اعداد و کدهای لاتین با **Geist Mono**.
- دکمه روشن/تیره/سیستم کنار نام کاربر؛ انتخاب در `localStorage` می‌ماند و قبل از رنگ‌آمیزی صفحه اعمال می‌شود تا پرش رنگ نبینید.
- کاملاً ریسپانسیو: منو در موبایل اسکرول افقی دارد، جدول‌های عریض داخل کارت خودشان اسکرول می‌شوند و صفحه اسکرول افقی نمی‌گیرد. اندازه فونت ورودی‌ها در موبایل ۱۶px است تا iOS هنگام تایپ زوم نکند.

## کاربران و احراز هویت

- ورود با **شماره موبایل + رمز عبور**. اولین بار که برنامه بالا می‌آید و هیچ کاربری وجود ندارد، صفحه ورود خودش فرم «راه‌اندازی اولیه» را نشان می‌دهد تا کاربر اول ساخته شود.
- بعد از آن، در صفحه **کاربران** می‌توانید همکارانتان را اضافه، ویرایش، غیرفعال یا حذف کنید و رمزشان را عوض کنید.
- رمزها با **scrypt** و نمک تصادفی هش می‌شوند (`scrypt$salt$hash`) و هرگز به‌صورت متن ذخیره نمی‌شوند؛ قابل بازیابی نیستند.
- نشست با یک کوکی `httpOnly` امضاشده با HMAC-SHA256 نگه داشته می‌شود (۳۰ روز). کلید امضا از `AUTH_SECRET` می‌آید — حتماً یک رشته تصادفی بلند بگذارید:
  ```bash
  node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"
  ```
- شماره موبایل هنگام ذخیره و ورود فقط به رقم تبدیل می‌شود، پس `۰۹۱۲۱۲۳۴۵۶۷` و `0912-123-4567` یکی حساب می‌شوند.
- همه کاربران دسترسی یکسان دارند (بدون نقش و سطح دسترسی). کاربر نمی‌تواند حساب خودش را حذف یا غیرفعال کند و آخرین کاربر فعال هم حذف نمی‌شود.
